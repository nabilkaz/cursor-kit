# Cursor Kit

For integration into another project, read `docs/QUICKSTART.md`; it is the copy-and-go contract. Read `docs/API.md` when using custom paths, inspection, or framework lifecycles.

The canonical engine is `src/cursor-theatre.js`. The studio's engine and index are generated by `npm run build`; edit `studio/editor.template.html` for scene-editor markup. Keep motion geometry separate from text reveal and orientation. Preserve reduced-motion handling and cleanup on disconnection.

Use system fonts without bundled font binaries. Keep native macOS cursor artwork out of tracked files. Preserve the MIT license and Liveblocks Apache-2.0 notices, including the component’s license comments. The GitHub repository is public. Keep the package private until the owner requests npm publication.

After engine edits, run `npm test` and `npm run build`, then exercise playback, pause, backward scrubbing, and the changed behavior in the browser. After UI edits, check the library, Scene Editor, and Cursor Designer at their actual viewport sizes.
