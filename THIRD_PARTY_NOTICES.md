# Third-party assets

The default canvas pointer uses the Liveblocks multiplayer cursor SVG path, under Apache-2.0. The source was adapted through sizing, fill, and stroke styling. See `licenses/LIVEBLOCKS-APACHE-2.0.txt` and https://github.com/liveblocks/liveblocks. The remaining bundled cursor variants are the project's recreated SVG tool shapes. Native macOS raster artwork from the original prototype is excluded from this repository and package.

Timeless Sans Grotesk is used by the demo and editors when installed locally. The Timeless Free Font License 1.2 permits use in works and restricts font redistribution. Obtain the family directly from https://timeless.co. `npm run fonts -- /path/to/family` copies the selected WOFF2 files and their license into the ignored `assets/fonts` directory. They are not included in the Git repository or npm package.

The project code is a private preview, with no open-source license granted yet. Third-party assets retain their own licenses.
