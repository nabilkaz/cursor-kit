# Third-party assets

The default canvas pointer uses the Liveblocks multiplayer cursor SVG path, under Apache-2.0. The source was adapted through sizing, fill, and stroke styling. See `licenses/LIVEBLOCKS-APACHE-2.0.txt` and https://github.com/liveblocks/liveblocks. The remaining bundled cursor variants are the project's recreated SVG tool shapes. Native macOS raster artwork from the original prototype is excluded from this repository and package.

Project code is licensed under MIT; see `LICENSE`. The Liveblocks pointer remains under Apache-2.0. The UI uses system fonts and does not bundle font files. The single-file component retains both license texts so copied components and standalone scene exports carry their notices.
